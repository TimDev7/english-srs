# English SRS

Маленькое приложение для интервальных повторений грамматики. Ванильный JS, без сборки и зависимостей.

## Запуск

Открой `index.html` в браузере. Прогресс хранится в `localStorage` (на каждом устройстве свой; есть экспорт/импорт на главной).

Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Как работает

- Каждое упражнение — карточка. Новые карточки вводятся по дневной квоте (по умолчанию 10), повторы ограничены потолком (по умолчанию 30).
- Интервалы (упрощённый SM-2): верно с первого раза → 1 день → 3 дня → предыдущий интервал × ease. Ошибка → интервал сбрасывается на 1 день, ease падает на 0.2 (минимум 1.3).
- Неверно отвеченная карточка возвращается в конец текущей сессии, пока не ответишь правильно (на расписание влияет только первая попытка).

## Свои упражнения

Редактируй `units.js`:

```js
{ t: "choice", q: "She ___ in London.", o: ["live", "lives"], a: "lives", e: "Объяснение" }
{ t: "fill",   q: "I ___ (go) home.",   a: ["went"],             e: "Объяснение" }
```

`a` для `fill` — массив допустимых ответов (например, с сокращением и без).
