# English SRS

Маленькое приложение для интервальных повторений грамматики. Ванильный JS, без сборки и зависимостей.

## Запуск

Открой `index.html` в браузере. Прогресс хранится в `localStorage` (на каждом устройстве свой; есть экспорт/импорт на главной).

Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Содержимое

Юниты 1–18 из English Grammar in Use (Murphy, 5th ed.): Present, Past, Present Perfect, Past Perfect, have/have got, used to. По 8 упражнений на юнит, всего 144. Нумерация совпадает с книгой, сами упражнения написаны с нуля, из книги ничего не скопировано.

## Как проходит юнит

1. **Теория** — короткий блок: формула, пункты, примеры, на что обратить внимание. Показывается перед первой карточкой юнита и всегда доступна на странице юнита (нажми на юнит на главной).
2. **Упражнения** — карточки с интервальными повторениями.
3. **Мои предложения** — пишешь свои предложения по заданию, отмечаешь чек-лист самопроверки. Часть предложения, которую хочешь запомнить, бери в `[квадратные скобки]`: из неё получится карточка, которая появится завтра. Кнопка «Скопировать на проверку» копирует предложения с правилом, чтобы вставить их в чат с Claude.

Ещё есть **диктант на слух**: браузер озвучивает предложения из уже пройденных карточек, ты вводишь их (нужна поддержка озвучки в браузере).

## Как работает

- Каждое упражнение — карточка. Новые карточки вводятся по дневной квоте (по умолчанию 10), повторы ограничены потолком (по умолчанию 30).
- Интервалы (упрощённый SM-2): верно с первого раза → 1 день → 3 дня → предыдущий интервал × ease. Ошибка → интервал сбрасывается на 1 день, ease падает на 0.2 (минимум 1.3).
- Неверно отвеченная карточка возвращается в конец текущей сессии, пока не ответишь правильно (на расписание влияет только первая попытка).

## Свои упражнения

Упражнения — `units.js`, теория и задания на свои предложения — `lessons.js`. Пример упражнения:

```js
{ t: "choice", q: "She ___ in London.", o: ["live", "lives"], a: "lives", e: "Объяснение" }
{ t: "fill",   q: "I ___ (go) home.",   a: ["went"],             e: "Объяснение" }
```

`a` для `fill` — массив допустимых ответов (например, с сокращением и без).
